# یادگیری دیجیتال دیزاین به سبک تِرِد

تِرِد ها پست‌ های کوتاه و فشرده‌ ای هستن که هدفشون انتقال سریع یک ایده یا مفهومه.  
ما در CS12 از همین ایده برای آموزش استفاده می‌کنیم؛ یعنی مباحث بزرگ رو به مفاهیم کوچک‌تر تقسیم می‌کنیم و هر کدوم رو به شکل یک تِرِد آموزش میدیم تا یادگیری ساده‌ تر، قابل‌ فهم‌ تر و کم‌ خسته‌ کننده‌ تر باشه.

این دوره از **Digital Logic** شروع میکنه و قدم‌ به‌ قدم مفاهیم پایه‌ مدار های دیجیتال رو میسازه.

این پروژه با استفاده از تمپلیت [NBT Theme](https://github.com/The-CS12/ntb-theme) ساخته شده.

### نحوه مشارکت یا اعلام مشکل

پروژه کاملاً **Open-source** هست.  
اگر در محتوای آموزشی، غلط املایی، ایراد علمی یا هر مشکل دیگه‌ای دیدید، می‌تونید یک **Issue** باز کنید.

همچنین خوشحال می‌شیم خودتون هم در نوشتن و بهبود تِرِدها مشارکت کنید. ❤️
